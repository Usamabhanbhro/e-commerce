# Usamabhanbhro Page Topology

| Route | Page | Primary behavior |
|---|---|---|
| `/` | Home | Editorial showcase, product discovery, journal, collection CTAs |
| `/shop` | Shop | Filters, sorting, product grid |
| `/collections` | Collections | Collection index |
| `/collections/:slug` | Collection detail | Editorial intro, filter, sort, product grid |
| `/products/:slug` | Product | Gallery, variants, quantity, bag, wishlist, related products |
| `/search` | Search | Local matching, empty state, result count, clear |
| `/cart` | Cart | Quantity, remove, subtotal, delivery, checkout |
| `/checkout` | Checkout | Contact, shipping, delivery, payment connector, demo outcomes |
| `/order-confirmation` | Confirmation | Order reference, payment state, items, totals, disclaimer |
| `/account` | Account | Profile, order history, saved items, address, preferences |
| `/wishlist` | Wishlist | Local saved products and clear action |
| `/journal` | Journal index | Editorial cards |
| `/journal/:slug` | Journal article | Hero, article content, related stories |
| `/about` | About | Brand and project concept |
| `/contact` | Contact | Local validation and success state |
| fallback | 404 | Styled recovery route |
